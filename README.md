# Multi-Author Blogging Platform

A full-featured multi-author blogging platform built with Django.

This project allows multiple authors to create, manage, and publish blog posts with categories, tags, comments, likes, search, filtering, and author dashboards.

---

## 🚀 Project Features

### Authentication System
- User Registration
- Login / Logout
- Secure authentication system
- Author-based permissions

### Blog Management
- Create Blog Post
- Update Blog Post
- Delete Blog Post
- Draft and Published status
- Automatic slug generation
- Featured image upload
- View counter

### Category & Tag System
- Create categories
- Assign categories to blogs
- Add multiple tags
- Filter blogs by category
- Filter blogs by tag

### Search & Pagination
- Search blogs by:
  - Title
  - Content
  - Category
  - Tags

- Pagination for blog listing

### Author Dashboard
Authors can view:

- Total Posts
- Published Posts
- Draft Posts
- Total Views
- Recent Posts

### Comment System
- Authenticated users can comment
- Display comments on blog details page
- Comment timestamps

### Like System
- Like blog posts
- Unlike blog posts
- Display total likes

### Public Author Profile

Each author has a public profile page showing:

- Author username
- Published blogs
- Total posts
- Total views
- Total likes received

### Django Admin Improvements

Customized admin panel with:

- Blog management
- Category management
- Tag management
- Comment management
- User statistics
- Search and filters
